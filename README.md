# Ultrasound–Microbubble Simulation

## 1. Project Overview

This project investigates the effects of ultrasound parameters on lipid-shell microbubble dynamics and explores acoustic-field simulation for a 16-element soft-piezoceramic transducer.

The microbubble system consists of:
- Lipid shell
- Fluorescent surrogate: AMC (7-Amino-4-methylcoumarin)
- Gas core: Nitrogen (N₂)

## 2. Research Objectives

1. Investigate how ultrasound frequency and pressure affect microbubble oscillation.
2. Estimate the modeled shell-rupture threshold.
3. Simulate the acoustic pressure field generated by a 16-element transducer.
4. Explore how transducer geometry and phase delays affect beam shape.

## 3. Mathematical Models

### 3.1 Bubble Dynamics

The bubble radius is represented by \(R(t)\), where \(R_0\) is the equilibrium radius.

The simulation uses a modified Rayleigh–Plesset equation and a Marmottant shell model.

**Model assumptions and limitations:**  
The predicted rupture threshold is model-dependent and requires validation against experimental measurements.

### 3.2 Transducer Acoustic Field

The acoustic field is simulated using k-Wave.

Parameters include:
- Center frequency
- Element width and pitch
- Source pressure
- Element phase delays
- Medium sound speed and density

## 8. Limitations

The simulation parameters are initial illustrative values, not validated measurements of the actual formulation. The effects of AMC on shell properties must be established experimentally. The transducer model does not directly simulate piezoelectric coupling.
